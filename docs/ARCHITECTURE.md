# আর্কিটেকচার

## মূল ধারণা

ফ্রেমটা **স্বচ্ছ জানালাওয়ালা PNG/WebP**। ক্যানভাসে আঁকার ক্রম (`js/core.js`, `one2()`):

1. ব্যবহারকারীর ছবি (বা ছবি না থাকলে "ছবি যোগ করুন" প্লেসহোল্ডার) — জানালার জায়গায়
2. তার **উপরে** ফ্রেম (জানালা স্বচ্ছ, তাই ছবি দেখা যায়; ফ্রেমের নিজের ধার ছবির কিনারা ঢাকে)
3. নামের বক্সে হালকা নীল রঙ দিয়ে ঢেকে নাম ও পদবী লেখা (পদবী লম্বা হলে দুই লাইন)

ডিজাইনার ফ্রেম বদলালেও এই ক্রম একই থাকে; শুধু মাপ বদলায় (`js/config.js`)।

ক্যানভাস দুইটা: `#c0`, `#c1` (দুই ফ্রেম)। যেটা `.main` সেটা উপরে বড়, অন্যটা `.alt` নিচে ছোট। ডাউনলোড/শেয়ারের সময় আলাদা অফস্ক্রিন ক্যানভাসে **২১৬০px**-এ আবার আঁকা হয় (`render()`), প্রিভিউ ১০৮০px।

## স্ক্রিপ্ট লোডের ক্রম

সব `js/*.js` ক্লাসিক স্ক্রিপ্ট, `defer` দিয়ে ক্রমে চলে, একই গ্লোবাল স্কোপ শেয়ার করে (বান্ডলার নেই)।
**ক্রম বদলাবেন না** — পরের ফাইল আগের ফাইলের ভেরিয়েবল ব্যবহার করে।

| ফাইল | কাজ |
|---|---|
| `config.js` | `CFG` (মাপ, তারিখ, লিংক, পদবীর তালিকা), `SRC`/`POSTER` পথ, `$`, `bn()` |
| `core.js` | স্টেট `st`, `draw()` (rAF ব্যাচ), `one2()` রেন্ডারার, প্লেসহোল্ডার, ফন্ট লোড |
| `layout.js` | এক-স্ক্রিন মাপ (`--M`), কিবোর্ড মোড, `setMain()` ফ্রেম বদল, সোয়াইপ |
| `photo.js` | ছবি বাছা/ছোট করা (≤২০০০px), প্রথম-ছবির টোস্ট, রিসেট |
| `fields.js` | নাম/পদবী ইনপুট, পদবী চিপ, লোকাল-স্টোরেজে মনে রাখা |
| `gestures.js` | ছবি টানা, দুই আঙুলে জুম, হুইল |
| `ui.js` | Back-বাটন লেয়ার (`pushL/popL/sheet`), ডায়ালগ `dlg()`, ভ্যালিডেশন `ready()`, যোগাযোগ পপআপ |
| `share.js` | ক্যাপশন, এক্সপোর্ট, সেভ, শেয়ার, পোস্টার শিট, রেজাল্ট শিট |
| `fx.js` | বাটন রিপল, ৩ডি টিল্ট, কাউন্টডাউন, ভেসে থাকা তারা ও ট্যাপ বার্স্ট |
| `pwa.js` | SW রেজিস্টার, ইনস্টল বাটন |

CSS-ও ক্রমে লোড হয় (`base → layout → components → overlays → features`); পরের ফাইল আগেরটা ওভাররাইড করতে পারে।

## গুরুত্বপূর্ণ সিদ্ধান্ত

- **এক স্ক্রিন:** `#app` ফিক্সড, উচ্চতা `visualViewport` থেকে; কিবোর্ড খুললে `KB` মোডে নিচের ছোট ফ্রেম লুকিয়ে বড় ফ্রেম বড় রাখা হয়।
- **Back বাটন:** শিট/পপআপ খুললে `history.pushState` হয়, Back চাপলে শুধু সেটা বন্ধ হয়। `sheet()` ও `dlg()` এটা সামলায়।
- **ছবি বাছাই:** `<label for="file">` দিয়ে সরাসরি, আর ফ্রেমে ট্যাপে `openPick()` (`showPicker` → `click` ফলব্যাক)।
- **নাম ও পদবী বাধ্যতামূলক:** `ready()` ছবি → নাম → পদবী ক্রমে যাচাই করে, প্রথম খালি ঘরের জন্য পপআপ দেখায়।
- **ফন্ট:** Hind Siliguri (Google Fonts)। ডাউনলোডের আগে `ensureFonts()` অপেক্ষা করে। নিজের সার্ভারে ফন্ট রাখলে MAINTENANCE.md দেখুন।
- **আইকন:** `index.html`-এর শুরুতে inline SVG স্প্রাইট; ব্যবহার `<use href="#i-নাম">`।

## PWA ও ক্যাশ

- `manifest.webmanifest`: standalone, আইকন ১৯২/৫১২/মাস্কেবল।
- `sw.js`: ইনস্টলে `PRECACHE` তালিকা ক্যাশ হয়। নেভিগেশন = নেটওয়ার্ক-আগে; নিজের ফাইল = ক্যাশ-আগে + পেছনে আপডেট; Google Fonts = আলাদা ক্যাশে।
- **নতুন ফাইল যোগ/নাম বদলালে** `PRECACHE` তালিকা ঠিক রাখুন এবং `VERSION` বাড়ান।
- `_headers`: HTML/JS/CSS/SW সবসময় যাচাই (`no-cache`), `assets/` ৭ দিন।

## পরিচিত সীমাবদ্ধতা

- ফেসবুক/মেসেঞ্জারের ইন-অ্যাপ ব্রাউজারে সেভ বাটন কাজ নাও করতে পারে — রেজাল্ট শিটে ছবি চেপে ধরে সেভ করার নির্দেশ আছে।
- আইফোনের HEIC ছবি কিছু ব্রাউজারে পড়া যায় না — বার্তা দেখানো হয়।
- পোস্টার ১০৬৬px; বেশি জুমে ঝাপসা। বড় ফাইল দিলে `assets/poster.jpg` বদলান।
- অ্যাক্সেসিবিলিটি: স্ক্রিন-রিডারের জন্য ক্যানভাসে টেক্সট নেই; পপআপে ফোকাস-ট্র্যাপ/Esc নেই।
